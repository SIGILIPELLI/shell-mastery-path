    A tiny subcommand CLI¶

    Build taskbook, a subcommand tool (add, done, list, stats) that keeps tasks in a file, uses declare -F for dispatch, reports errors on stderr with exit status 2 and cleans up with a trap. Run it with 2>&1 to see messages in order. It runs against a temporary file, so nothing on your system is touched.

    Starter code

    #!/usr/bin/env bash
# taskbook: a tiny subcommand CLI storing tasks in a file (runs in a temp dir)
set -euo pipefail
DB=$(mktemp)
trap 'rm -f "$DB"' EXIT

die() { echo "error: $*" >&2; return 2; }

# TODO: cmd_add <title...>   append "<id>|open|<title>" (id = number of lines + 1), print "added #<id>"; with no title call die and return its status
# TODO: cmd_done <id>        mark open -> done with sed (write a new file, then mv); "completed #<id>", "#<id> already done" (status 0),
#                            or die "no task #<id>" for an unknown id; wrong argument count -> die "done needs one id"
# TODO: cmd_list [all|open|done]   print "<id> [x] title" for done tasks and "<id> [ ] title" for open ones
# TODO: cmd_stats            print "open=N done=M" with awk
# TODO: main                 dispatch "<cmd>" to cmd_<cmd> with declare -F, unknown -> die "unknown command: <cmd>"

main add Buy milk
main add Write report
main add Call Ana
main done 2
main done 2
main done 9 || echo "rc=$?"
main add || echo "rc=$?"
main list
main list open
main stats
main frobnicate || echo "rc=$?"

    #!/usr/bin/env bash
# taskbook: a tiny subcommand CLI storing tasks in a file (runs in a temp dir)
set -euo pipefail
DB=$(mktemp)
trap 'rm -f "$DB"' EXIT

die() { echo "error: $*" >&2; return 2; }

cmd_add() {
  [ $# -ge 1 ] || { die "add needs a title"; return; }
  local id=$(( $(wc -l < "$DB") + 1 ))
  printf '%d|open|%s\n' "$id" "$*" >> "$DB"
  echo "added #$id"
}

cmd_done() {
  [ $# -eq 1 ] || { die "done needs one id"; return; }
  grep -q "^$1|" "$DB" || { die "no task #$1"; return; }
  grep -q "^$1|done|" "$DB" && { echo "#$1 already done"; return 0; }
  sed "s/^$1|open|/$1|done|/" "$DB" > "$DB.new" && mv "$DB.new" "$DB"
  echo "completed #$1"
}

cmd_list() {
  local filter=${1:-all}
  while IFS='|' read -r id state title; do
    [[ $filter == all || $filter == "$state" ]] && printf '%s [%s] %s\n' "$id" "$([[ $state == done ]] && echo x || echo ' ')" "$title"
  done < "$DB"
  return 0
}

cmd_stats() {
  awk -F'|' '{n[$2]++} END {printf "open=%d done=%d\n", n["open"], n["done"]}' "$DB"
}

main() {
  local c=${1:-help}; shift || true
  if declare -F "cmd_$c" > /dev/null; then "cmd_$c" "$@"; else die "unknown command: $c"; fi
}

main add Buy milk
main add Write report
main add Call Ana
main done 2
main done 2
main done 9 || echo "rc=$?"
main add || echo "rc=$?"
main list
main list open
main stats
main frobnicate || echo "rc=$?"

    Each subcommand is a function, the dispatcher checks for it with declare -F and unknown commands fail with a message and status. The sed-to-new-file-then-mv pattern avoids the non-portable sed -i. Verified by running it with Bash 5.3 on macOS (output captured with 2>&1).

    A validated sales report with associative arrays¶

    Read a small CSV, skip and report invalid rows on stderr, total amounts per region with a Bash 4+ associative array (arithmetic in awk for decimals) and print regions ranked by total. Run it with Bash 4 or later (macOS ships 3.2, so install a newer bash) and with 2>&1.

    Starter code

# sales report: validate rows, total per region with an associative array, rank regions
set -euo pipefail
TMP=$(mktemp -d); trap 'rm -rf "$TMP"' EXIT

region,rep,amount
north,ana,1200.50
south,bo,800
north,cy,300.25
east,di,abc
west,ed,
south,fy,450.75
north,gu,-20
east,hy,950
CSV

    #!/usr/bin/env bash
# sales report: validate rows, total per region with an associative array, rank regions
set -euo pipefail
TMP=$(mktemp -d); trap 'rm -rf "$TMP"' EXIT
cat > "$TMP/sales.csv" <<'CSV'
region,rep,amount
north,ana,1200.50
south,bo,800
north,cy,300.25
east,di,abc
west,ed,
south,fy,450.75
north,gu,-20
east,hy,950
CSV

declare -A total count
bad=0 line=0
while IFS=, read -r region rep amount; do
  line=$((line + 1))
  [ "$line" -eq 1 ] && continue
  if [[ ! $amount =~ ^[0-9]+(\.[0-9]+)?$ ]]; then
    echo "skip line $line: invalid amount '${amount}' for $rep" >&2
    bad=$((bad + 1)); continue
  fi
  total[$region]=$(awk -v a="${total[$region]:-0}" -v b="$amount" 'BEGIN {printf "%.2f", a + b}')
  count[$region]=$(( ${count[$region]:-0} + 1 ))
done < "$TMP/sales.csv"

for r in "${!total[@]}"; do echo "$r ${total[$r]} ${count[$r]}"; done | sort -k2,2nr | while read -r r t c; do
  printf '%-6s %9s (%d sales)\n' "$r" "$t" "$c"
done
echo "skipped: $bad"

    Validation with a regex stops bad data early, awk does the decimal arithmetic bash cannot, and sorting a generated listing gives a stable ranking because associative array order is unspecified. Verified by running it with Bash 5.3 on macOS (output captured with 2>&1).
