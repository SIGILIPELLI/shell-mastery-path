# Shell Mastery Path

A free, structured, module-wise Bash/shell scripting training program — entry level to master level, with runnable code in every module and a hands-on project at the end of each level.

**Live site:** https://sigilipelli.github.io/shell-mastery-path/

## Contents

- **Level 1 · Entry** — shell foundations
- **Level 2 · Intermediate** — idiomatic, testable shell scripts
- **Level 3 · Advanced** — robustness, security, distribution
- **Level 4 · Master** — production automation & systems

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install mkdocs-material
.venv/bin/python -m mkdocs serve
```
